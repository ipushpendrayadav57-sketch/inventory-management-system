# StockOS — Inventory & Ecommerce Management

Modern inventory foundation for purchase, stock IN/OUT, sales, warehouses, returns and ecommerce integrations.

## Run
npm install
npm run dev

## Roadmap
- PostgreSQL + Prisma persistence
- Authentication and role-based permissions
- Purchase orders + GRN + vendor ledger
- Warehouse/bin inventory ledger
- Sales/POS + returns/RTO
- Barcode scanning and labels
- Amazon/Flipkart/Myntra/Meesho/Shopify connectors
- GST, accounting and advanced reports
- Background sync, webhooks and audit logs
